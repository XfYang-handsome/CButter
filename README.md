# CButter

CButter 是一个用 C 重新实现的 Butter 编程语言。

> 当前版本未完成，仅作备份与语法说明使用。

## 语法概览

CButter 使用中缀表达式风格，语法设计简洁可读。

### 1. 函数定义

函数定义格式：

```text
func/run <函数名>([<参数名1>, {类型1}], [<参数名2>, {类型2}], ... ) -> {返回类型1}, [{返回类型2}, ...] {
    // 函数体
}
```

- `func`：表示定义一个函数，但程序启动时不自动运行。
- `run`：表示程序启动时自动执行该函数。
- `函数名`：仅允许字母、数字和下划线，且必须以字母或下划线开头。
- 返回值：如果函数无返回值，使用 `void`。
- 只要有一个返回值，返回类型列表中就不能出现 `void`。

### 2. 变量定义

#### 全局变量

```text
global <变量名1>, [<变量名2>, ...] {变量类型} [= <值1>, <值2>, ...]
```

#### 局部变量

```text
butter <变量名1>, [<变量名2>, ...] {变量类型} [= <值1>, <值2>, ...]
```

- 全局变量使用 `global` 定义。
- 局部变量使用 `butter` 定义。
- 在函数内部访问变量时，优先使用局部变量；如果局部变量不存在，则使用全局变量。

## 注意事项

- 语法仍处于暂定阶段，可能会继续调整。
- 当前文档仅用于说明 CButter 的基本语法规则。

## 示例

```text
func say_hello() -> void {
    butter message string = "Hello, CButter!"
    print(message)
}

run main() -> void {
    say_hello()
}
```

> 以上示例仅为语法参考，具体实现与标准库尚未定义。
