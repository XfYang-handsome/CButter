# CButter
The Butter programming language that is remade by C.

CButter语法规则（暂定）：

CButter使用中缀表达式。

1、函数定义：func/run <函数名> ([<初始变量1>, {类型1}], [<初始变量2>, {类型2}]...) -> {返回类型1}, [{返回类型2}...] {}

说明：函数名只能包含字母、数字和下划线，其中只能以字母或下划线开头。

若函数没有返回值，则返回类型1写为void，一旦有至少一个返回值，返回类型便不能有void。

func关键字表示程序开始时不运行，run关键字表示程序开始时运行。

2、变量定义

全局变量使用global关键字：global <变量名1>, [<变量名2>...] {变量类型} [= <值1>, <值2>...]

局部变量与全局变量定义方式相同，关键字改为butter关键字。

函数中调用变量时，优先局部，其次全局。
